## Refactored OpenAI API Notebook

This repository contains the refactored OpenAI API notebook:

- `refactored Open AI API.ipynb`

## Tests

The notebook includes a Step 6 testing section. The tests check:

- product information extraction with `extract_product_info()`
- valid listing validation with `validate_listing()`
- invalid listing validation with a missing required field
- formatted error output with `format_error()`
- invalid API JSON response handling with `parse_api_response()`
- invalid JSON save data handling with `save_json()`
- full processing with one product using `process_multiple_products()`
- successful creation of the output files

Inline checkpoint tests were removed from the function sections so the notebook can be read from top to bottom with the tests grouped in one place.
